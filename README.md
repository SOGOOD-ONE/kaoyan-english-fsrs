# 考研英语核心词 FSRS

## 核心算法介绍

本项目的核心算法是 `FSRS`（Free Spaced Repetition Scheduler）。

它根据单词卡片的记忆状态，动态计算下次复习时间，而不是固定间隔重复。每张卡都会维护这些关键状态：

- `state`
- `stability`
- `difficulty`
- `due`
- `reps`
- `lapses`

算法目标很简单：

1. 让记得牢的词拉长间隔
2. 让容易忘的词更快回到队列
3. 让每天的复习量尽量稳定

## 算法流程

### 1. 词库导入

系统词库先进入 `Vocabulary`、`Word`、`VocabularyWord` 这三层结构。

### 2. 今日计划生成

每天会根据当前启用词库，生成：

- 昨日新词复习任务
- 今日新词学习任务
- 自主复习任务

### 3. 学习与评分

用户答题后，前端会把结果交给 `FSRS`：

- `Again`
- `Hard`
- `Good`
- `Easy`

FSRS 根据这次评分更新卡片状态，并计算下一次复习间隔。

### 4. 同步

本地学习记录会先写入 IndexedDB，再同步到服务端，保证离线也能继续学。

## 算法功能

- 新词学习队列
- 昨日新词复习
- 自主复习推荐
- 复习间隔自动调整
- 学习进度统计
- 本地与服务端同步
- 异常卡片自动归一化，避免卡在无效状态

## 词库能力

- 系统词库自动导入
- 用户词库可导入、启用、删除
- 删除词库后会重新计算当天计划

## 运行说明

- 前端：Vite
- 后端：Flask + SQLAlchemy
- 存储：SQLite / 数据库配置项
